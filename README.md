# Mafiozo

A BitLife-style life simulator set in the criminal underworld of Velmora City.
Start as a kid in the Narrows, commit crimes, dodge the cops, build respect, survive prison, and see how far you rise before the city buries you.

Play on a phone: open the GitHub Pages link and use "Add to Home Screen" to install it like an app.

Plain HTML, CSS and JavaScript. No build step. Open `index.html` to play locally.
